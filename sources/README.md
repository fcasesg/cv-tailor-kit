# Sources

Drop raw material about your career here. Claude can use it to build and enrich your master CV.

Useful things to add:
- **LinkedIn profile as PDF**: on your LinkedIn profile, click "Resources" (or "More") then "Save to PDF"
- **Old CVs and cover letters** (PDF, Word or text)
- **Performance reviews, promotion cases, peer feedback**
- **Project write-ups, launch announcements, results dashboards** (screenshots are fine)
- **Awards, certificates, courses**

Everything in this folder except this README is git-ignored, so it stays private.
