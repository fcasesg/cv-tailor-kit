# Stories

Put your work stories here, one Markdown file each (for example `onboarding-redesign.md`).

A good story covers:
- **Situation**: company, team, what was going on
- **Task**: what you were responsible for
- **Actions**: what *you* did (not the team)
- **Results**: numbers wherever possible (+X% conversion, £Y revenue, Z hours saved)

`/tailor` reads these to find evidence for a specific job, especially for the cover letter.
The same stories double as prep for behavioural interviews ("Tell me about a time when...").

Everything in this folder except this README is git-ignored, so it stays private.
